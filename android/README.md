# AgriDirect Android app

This folder contains the native Kotlin/Jetpack Compose mobile app. It mirrors the mobile web experience with a splash screen, farmer/buyer mode, marketplace, product details, order tracking, profile, and bottom navigation.

## Run in Android Studio

1. Open the `android` folder in Android Studio.
2. Allow Gradle sync and install an Android 8.0+ emulator or connect a device.
3. Select the `app` configuration and press Run.

The app uses sample data for the prototype. The shared REST contract for connecting it to the backend is documented in `../AGRIDIRECT.md`.
